# 実機テスト手順

この文書は、コードを取り込んだあとにWindows版Excelで確認する項目をまとめたものです。

## 1. 事前確認

1. ブックが`.xlsm`形式で保存されている。
2. `modDnsApi`、`modDnsTrace`、`modDnsSamples`が標準モジュールとして存在する。
3. VBEの`デバッグ`→`VBAProjectのコンパイル`がエラーなく完了する。
4. 学校・会社の端末では、担当者が許可した範囲で実行する。

## 2. 最小テスト

1. `DNS_初回セットアップ`を実行する。
2. `Trace`と`DnsResults`の2シートが作成されることを確認する。
3. `DNS_ローカルテスト`を実行する。
4. 成功してレコードリストが返った各TraceIdに`FREE / OK`が記録されることを確認する。
5. `DnsResults`で`localhost`のAまたはAAAAを確認する。

一般的には、Aは`127.0.0.1`、AAAAは`::1`です。ただし、Windowsのhostsやネットワーク設定が変更されている端末では異なることがあります。結果の相違だけで不具合と判断しないでください。

## 3. TraceIdの確認

1. `DNS_名前と種類を指定して検索`を2回実行する。
2. 2回の`TraceId`が異なることを確認する。
3. 各TraceIdで`VALIDATE`→`QUERY`→`RESOLVE`→`PARSE_RECORD`→`COMPLETE`→`FREE`の流れを絞り込む。

DNSエラーの場合は`PARSE_RECORD`がなく、`COMPLETE / ERROR`になります。レコードリストが返っていない場合、`FREE`がないことは正常です。

## 4. レコード種類別テスト

対象ドメインのレコードは変更されます。実行前に、自分で管理している試験用ゾーンまたは授業で指定されたドメインを用意するのが最も確実です。

| 種類 | 入力 | 確認点 |
|---|---|---|
| A | `localhost` | ドット区切りIPv4として表示される |
| AAAA | `localhost` | コロン区切りIPv6として表示される |
| CNAME | CNAMEを設定した試験名 | 参照先名が表示される |
| PTR | `DNS_IPv4逆引きテスト` | 逆引き名へ変換される。回答の有無は環境依存 |
| MX | MXを持つ試験ドメイン | preferenceとexchangeが表示される |
| TXT | TXTを持つ試験ドメイン | 複数文字列が` | `で区切られる |

`example.com`は文書用に予約された安全な例示ドメインですが、すべての種類の回答が常に存在する保証はありません。

## 5. 異常系テスト

### 空の問い合わせ名

`DnsQueryRecords("", "A")`をイミディエイトウィンドウまたは一時マクロから実行し、Traceに「問い合わせ名が空」と記録されることを確認します。

### 未対応の種類

`DnsQueryRecords("localhost", "SRV")`を実行し、未対応種類として記録されることを確認します。

### 存在しない名前

自分が管理する試験用ドメイン配下の、存在しない名前をAで問い合わせます。`DNS_ERROR_RCODE_NAME_ERROR`または環境に応じたエラーがTraceへ記録され、Excelが停止しないことを確認します。

### 外部通信を遮断した状態

管理者が許可した試験環境だけで行います。外部名の問い合わせがエラーまたはタイムアウトになり、ローカル名のテストは環境に応じて動作することを確認します。

## 7. 連続実行テスト

メモリ解放漏れを観察するには、A問い合わせを100回繰り返し、次を確認します。

- 成功してレコードリストが返った各TraceIdに`FREE / OK`が記録される。
- Excelのメモリ使用量が一方向に大きく増え続けない。
- TraceIdが問い合わせごとに異なる。
- Excelが応答不能または異常終了しない。

このテストは「100回レビュー」とは別です。実行回数だけで品質を保証するものではなく、32bit/64bitの両方で構造体解析を確認する必要があります。
